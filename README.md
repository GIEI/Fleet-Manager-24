First public release: a simple but useful addon manager for **Microsoft Flight Simulator 2024**.

### Features
- **Tile grid** — one tile per DLC, with thumbnail from `ContentInfo/` folders
- **AIRAC cycle** — reads `cycle.json` from the addon or WASM cache and shows the cycle on each tile
- **WASM cache** — delete WASM cache per aircraft directly from the tile
- **Hide tiles** — select and hide tiles; restore via Show All
- **Dev Manager** — filter visible developers and configure dev site URLs
- **Right-click menu** — open Community folder, WASM folder, edit manifest or developer website
- **Auto-detection** — detects FS2024 via Steam or Microsoft Store, reads Community folder from `UserCfg.opt`
- **Navigraph AIRAC** — manage AIRAC cycle (right click on the AIRAC header)

### Requirements
- Windows 10/11 x64
- No .NET installation required (self-contained)

### Installation
Unzip and run `FleetManager.exe`. No installer needed.
